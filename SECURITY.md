# Security policy

## Reporting a vulnerability

Report security issues privately to **theo@crevon.me**. Do not open a
public GitHub issue for a suspected vulnerability.

Include what you found, the version and platform you tested, and, if you
have one, a minimal reproduction. You should get an acknowledgement within
**7 days**.

## Supported versions

trousseau has not reached 1.0 yet. There is no supported-versions table
until the first 1.0 release; until then, only the latest commit on the
default branch receives fixes.

| Version | Supported |
|---|---|

## Scope

This policy covers the trousseau CLI and library crates in this
repository. It does not cover third-party dependencies; report those
upstream.

## Bug bounty

There is no bug bounty program.
